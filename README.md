# 🧠 AI-Assisted Surgical Tumor Simulation

A Blender-based biomedical visualization project demonstrating surgical tool interaction with tumor treatment and removal simulation.

---

## 🎯 Project Overview

This project simulates a simplified surgical workflow involving:

- Organ representation
- Tumor visualization
- Surgical tool interaction
- Tumor response/removal
- Before vs After comparison

The objective is to visualize biomedical concepts in an interactive and understandable way.

---

## 🔬 Biomedical Relevance

This project can be useful for:

- Medical education
- Surgical visualization
- Digital twin concepts
- Biomedical simulation learning
- Patient understanding
